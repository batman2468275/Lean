# Animation and look check

Contact sheets (ten pinned `?p=` frames per page, at 1440x900 and 390x844, plus the Home intro) are generated by `tools/contact.cjs`, `tools/intro.cjs` and `tools/sheet.py` (see CLAUDE.md).
They are regenerated at the end of each round of work, so the PNGs here always match the current site. Captured with software WebGL: they show poses and layout, not smoothness.
